Ponko is an offline-capable AI app for Android: chat (image, file and document input) +
drawing + tagging, each of which can be served over its own OpenAI-compatible API.
All inference runs on-device: apart from the optional in-app LoRA download, no feature
needs the network. No telemetry; your data stays on your phone.
See the [README](https://github.com/visitor257/Ponko#readme).

Installs over 2.1.0. Models and settings carry across.

## What's new

### A search button on the Ponko-EX page

The plugin list used to carry a full-width search box under the toolbar, always visible. With
one or two plugins installed that is a whole row of height spent on something you never
touch. It is now hidden by default and opened by a magnifier in the top-right corner, in the
same place the chat page keeps its gear and plus buttons.

Matching is case-insensitive and covers the display name, the package name and the manifest
display name, so typing `voxcpm` finds `com.litertchat.ponko.voxcpm2` as well as the card
title.

Collapsing the search clears the query. An invisible box still filtering the list is how you
end up wondering where two of your plugins went.

The button only appears on the card list, not inside a plugin's own UI, since there are no
cards to search there.

### Fixed: the plugin About dialog was unreadable in the light theme

Reported as dark text on a dark background. The cause was not the dialog itself:

```
onCreate             theme resolved, setTheme(light or dark)     once
in-app theme switch  palette re-resolved, UI rebuilt             no setTheme
```

So starting with the system in dark mode and then picking light inside the app left the
Activity on the dark theme while the palette had already gone light. A dialog created after
that took its background from the stale dark theme and its text colour from the new light
palette. The reverse arrangement — system light, app dark — was broken the same way and would
have shown light on light.

Fixed at both levels. Switching the theme in-app now re-applies the Activity theme, which
fixes every dialog created afterwards, not just this one. And the About dialog no longer
takes colours from the theme at all: background, title and body come from the palette, and
the title is an ordinary TextView rather than `setTitle()`, whose text colour the framework
theme controls.

## Known limits

Unchanged from 2.1.0 — see that release's notes. The two configurations still untested are
PixArt Alpha (the 512 variant) and MOSS-Image at its recommended CFG.

## 中文说明

Ponko 是一个可离线运行的 Android AI 应用：对话（支持图片、文件、文档输入）+ 绘图 + 打标，
三者都能各自开一个 OpenAI 兼容 API。所有推理都在设备本地完成——除了可选的 App 内 LoRA

### 新增：Ponko-EX 页的搜索按钮

插件列表原来在工具栏下面常驻一整条全宽搜索框。只装一两个插件时，那是白白占掉一行高度、
你永远不会去点的东西。现在默认收起，由右上角的放大镜打开——和对话页 ⚙/＋ 在同一个位置。

匹配不分大小写，覆盖显示名、包名和 manifest 里的显示名，所以搜 `voxcpm` 既能看到卡片标题，
也能命中 `com.litertchat.ponko.voxcpm2`。

收起时会清空查询。一个看不见却还在过滤列表的输入框，正是「我的插件怎么少了两个」的来源。

按钮只在卡片列表页出现，插件自己的界面里没有卡片可搜，那里不显示。

### 修复：插件「关于」弹窗在亮主题下看不清

报告的现象是暗底暗字。问题不在弹窗本身：

```
onCreate           解析主题、setTheme(亮/暗)        只跑一次
App 内切主题        重新解析配色、重建界面            没有 setTheme
```

所以「启动时系统是深色、之后在 App 里选亮色」会让 Activity 停留在深色主题，而配色已经变亮。
此时创建的弹窗，背景取自陈旧的深色主题、文字颜色取自新的亮色配色。反过来（系统亮、App 暗）
同样坏，会表现为亮底亮字。

两层都修了。App 内切换主题现在会重新应用 Activity 主题，这修好的是**之后创建的所有弹窗**，
不止这一个。另外「关于」弹窗彻底不再从主题取色：背景、标题、正文全部来自配色表，
标题改成普通 TextView 而不是 `setTitle()`——后者的文字颜色由框架主题控制。
