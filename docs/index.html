整套本地 AI 技术栈A whole local AI stack

每一块都在手机上跑。没有云端账户，也不需要联网 —— 除了你自己去下载模型的那一刻。 Every piece runs on the phone. No cloud account, and no network needed — except the moment you fetch a model yourself.

多模态对话Multimodal chat

双后端：LiteRT-LM 与 llama.cpp。可发图片、文件和文档，思考过程与正文分开显示，支持中断与继续。 Two backends: LiteRT-LM and llama.cpp. Send images, files and documents; reasoning is shown apart from the answer, and you can interrupt and resume.

.litertlm.ggufmmproj

本地绘图On-device drawing

内置 stable-diffusion.cpp。文生图与图生图、可选 Vulkan GPU 加速、TAESD 加速解码，还能看逐步生成的过程预览。 Bundled stable-diffusion.cpp. Text-to-image and image-to-image, optional Vulkan GPU, TAESD for faster decoding, plus a step-by-step progress preview.

把手机当服务器Use the phone as a server

把已加载的模型开成 OpenAI 兼容接口，电脑上的客户端或 Agent 都能连。对话与绘图各一套，端口独立、可只开其中一个。 Expose loaded models over an OpenAI-compatible API so desktop clients and agents can connect. Chat and drawing are separate services with their own ports.

插件式扩展Plugin extensions

语音合成这类能力放在独立 APK 里，不必都塞进主程序。协议公开，第三方插件同样能用，你也可以自己写。 Capabilities like speech synthesis ship as separate APKs instead of being crammed into the app. The protocol is public — third-party plugins work, and you can write your own.

隐私是设计而不是选项Privacy by design, not a setting

没有账号、没有自动遥测、没有默认联网。模型、会话、图片都留在应用私有目录里 —— 想分享什么，你自己决定。 No account, no automatic telemetry, no default network access. Models, chats and images stay in the app's private storage — what leaves is up to you.

扩展Extend

能力可以长在插件里Capabilities can grow as plugins

插件是独立 APK，跑在自己的进程里：它崩了不会拖死 Ponko。宿主负责渲染界面，插件只提供数据 —— 所以深浅色、圆角、布局都是统一的。 A plugin is a separate APK in its own process: if it crashes, Ponko survives. The host renders the UI and the plugin only supplies data, so theming and layout stay consistent.

Ponko-EX · 插件开发仓库Ponko-EX · plugin development repo

中英双语的插件开发手册、示例插件，以及第一个发布版 VoxCPM2 本地语音合成。也可以直接拿它当自己插件的起点。 A bilingual plugin guide, sample plugins, and the first release: VoxCPM2 local speech synthesis. Use it as the starting point for your own.
